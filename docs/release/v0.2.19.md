# QUBE 0.2.19

- Pull request review on routes without shell access: those reviewers now receive the review diff directly, with instructions that match the tools they can use.
- More trustworthy review results: a finding that points at code that is not in the reviewed change is rejected, and review changes are measured from the point where the branch diverged, so already-merged work is not reviewed again.
- Clearer review failures: when a review result is rejected, the result names the rule it failed, and an incomplete review lane no longer counts as a passing review.
