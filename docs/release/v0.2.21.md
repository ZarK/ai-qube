# QUBE 0.2.21

- Review turn budgets and timeouts are sized from the review input. The route `maxTurns` and `timeoutSeconds` values are minimums with no upper limit, and the gate no longer tells the author to split a pull request.
- A review lane on a route without shell that leaves changed files unread continues over those files in the same gate run. A lane that stops for capacity without inspecting the change is a host fault and fails over to the configured second host.
- A re-review round covers only the files changed since the approved head. Files a lane did not inspect are recorded as evidence.
- The review diff is prepared once per gate for lanes without shell.
- Finding citations are checked at the reviewed head, and a Grok review that reports no tool calls is reported truthfully.
- A model result that is not terminal is reported as such, whichever contract rule fails first.
- A review that did not complete is published as incomplete on GitHub and GitLab.
