# QUBE 0.2.20

- Fixes the 0.2.19 break in pull request review: lane evidence that cites review-input diff files no longer causes the gate to reject the result, so reviews on routes without shell are published again.
- Review routes without shell now receive the review diff and a prompt that matches their tools.
- Review findings that point at code missing from the reviewed head are rejected, and review changes are measured from the point where the branch diverged.
- A rejected review result names the contract rule it failed, and a review lane that did not complete no longer counts as a passing review.
- `qube review doctor` reports a degraded publisher, instead of a failure, when the permissions it reads prove that issue and label writes are allowed.
