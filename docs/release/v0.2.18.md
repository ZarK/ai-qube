# QUBE 0.2.18

- Persistent local development mode: a workspace can stay in local mode so day-to-day work does not need shipping setup, and switch back when it is time to publish.
- Host switching from the command line: list and switch agent harnesses without editing configuration files.
- More reliable Quality measurements: stage output and file selection are steadier, template and interpolation content is counted correctly, and build output folders no longer distort results.
- New isolated review adapters for Claude Code and OpenCode, so pull request reviews can be offloaded to either harness in a fresh read-only session.
- Windows review routes fixed: the Cursor route resolves correctly when run from inside a Cursor session, and harnesses installed through npm shims start reliably.
- More accurate acceptance checks: configuration keys mentioned in requirement text are no longer mistaken for files.
